# NeuroMesh VS Code & Cursor IDE Extension

Official native extension for **NeuroMesh V2 — Nature-Inspired MCP Context Intelligence Engine**.

## 🌟 Features

- **Live Status Bar**: Displays real-time token reduction and active MCP state.
- **Embedded 3D Monitor Webview**: Click the status bar or run `NeuroMesh: Open 3D Neural Monitor` to inspect your project graph directly inside your editor.
- **Instant Workspace Re-indexing**: Keep graph nodes and synapses in sync with a single click.
- **Context Activation on Selection**: Right-click any code block to evaluate minimal reversible context.

## 🚀 Quick Setup in Cursor or VS Code

1. Copy or link this folder into `~/.vscode/extensions/vscode-neuromesh` or `~/.cursor/extensions/vscode-neuromesh`.
2. Start the NeuroMesh monitor:
   ```bash
   neuromesh monitor
   ```
3. Enjoy zero-latency neural context in your coding agent!
