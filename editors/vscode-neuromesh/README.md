# NeuroMesh VS Code extension

Companion UI for the NeuroMesh MCP server (optional — MCP works without it).

**Agent loop (v0.9.0):** `get_context_packet` with **prompt only** (default `engine: fast`) → `expand_fold` / `expand_gap` → `record_feedback`. Check `retrieval.resolution_tier`, `retrieval.cache_hit`, and `coverage.claim`.

Install NeuroMesh first: [install guide](../../docs/agent-guide.md).
