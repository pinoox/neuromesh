NeuroMesh

Built for AI-assisted coding
v0.8.3 — ready to use Rust 1.80+ MCP stdio MIT License

Your AI agent does not need three thousand lines of boilerplate to fix one bug. NeuroMesh reads your repo like a map: it routes to the right symbols, sends a tight evidence packet to the model, and folds everything else into one-line markers you can expand when needed.

How it works

Keep structure. Cut tokens.

NeuroMesh never deletes your code. It folds what the task does not need into a single reversible line — like a table of contents that still knows where every function lives.

🧬

What you need — open

The functions and files that match your task stay fully visible with real bodies.

📦

What you do not — folded

Everything else becomes a one-line marker with a fold ID. Signatures and imports stay in view.

⚡

Need the body? One tool call

Run neuromesh_expand_fold — instant restore from memory, no grep hunt.

You keep the map. The model stops reading the encyclopedia.

Tune it

Two knobs. Sensible defaults.

Start with the built-in graph — it is faster and more precise for daily coding. Optional: plug in an external code graph (CBM) for get_context_packet only; folding and trace stay local.

🌿

Where context comes from

native (default) · auto · proxy_cbm. Auto picks up CBM if your IDE already has it. Change in Settings or one CLI command.

neuromesh config graph-backend auto
neuromesh doctor --proxy --probe
🔑

How prompts find symbols

keywords_expanded (default) works great for mixed NL + code. Try hybrid for vague prompts without client keywords.

neuromesh config seed-engine hybrid
neuromesh monitor  # Settings UI

Get started

Install NeuroMesh

One command, then neuromesh doctor to verify, and neuromesh connect to wire your editor.

Terminal 
curl -fsSL https://raw.githubusercontent.com/pinoox/neuromesh/main/install.sh | bash
PowerShell 
irm https://raw.githubusercontent.com/pinoox/neuromesh/main/install.ps1 | iex
Build from source (rustup 1.80+) 
git clone https://github.com/pinoox/neuromesh.git
cd neuromesh
cargo build --release --bin neuromesh
Cargo install 
cargo install --git https://github.com/pinoox/neuromesh.git neuromesh-cli --bin neuromesh
After install 
neuromesh doctor
neuromesh connect    # write MCP configs for this repo
Plug in your editor

Connect in one command

NeuroMesh speaks MCP over stdio — the standard protocol Cursor, Claude, VS Code, Windsurf, Zed, and dozens of agents already support. No cloud. No API key for indexing. Your code stays on your machine.

MCP config snippet 
{
  "mcpServers": {
    "neuromesh": {
      "command": "neuromesh",
      "args": ["mcp"]
    }
  }
}

What your agent can call

Teach the agent this loop: get_context_packet → expand a fold if needed → trace callers → record_feedback after a good edit.

get_context_packet
Start here — compact skeletons, fold IDs, coverage hints
neuromesh_expand_fold
Restore one folded function body — no disk grep
neuromesh_trace
Follow call and import chains
neuromesh_search_symbols
Find symbols when coverage is partial
neuromesh_get_dependencies
See what a file imports and calls
neuromesh_analyze_impact
Blast radius before you refactor
neuromesh_get_architecture
Languages, packages, entry points at a glance
neuromesh_record_feedback
One line after a good edit — routes improve next time
neuromesh_get_project_memory
Project facts from manifests and docs
neuromesh_explain_packet
Debug why a file was selected or dropped
neuromesh_get_file_skeleton
Fold a single file on demand
neuromesh_get_stats
